# Настройка UID для MEXC Trader

## Как получить UID

### Способ 1: Автоматический (рекомендуется)
```bash
npm run get-uid
```
Этот скрипт откроет браузер и поможет вам получить UID автоматически.

### Способ 2: Ручной
1. Откройте браузер и войдите в MEXC
2. Нажмите F12 для открытия DevTools
3. Перейдите на вкладку "Application" (или "Приложение")
4. В левом меню выберите "Cookies" → "https://www.mexc.com"
5. Найдите cookie с именем `u_id` и скопируйте его значение

## Как установить UID

### Вариант 1: Переменная окружения (рекомендуется)
```bash
# Windows
set MEXC_UID=ваш_uid_здесь

# Linux/Mac
export MEXC_UID=ваш_uid_здесь
```

### Вариант 2: Прямо в config.ts
Откройте `src/config.ts` и замените:
```typescript
mexcUid: process.env.MEXC_UID || "",
```
на:
```typescript
mexcUid: "ваш_uid_здесь",
```

## Запуск
```bash
npm run dev
```

## Мониторинг
- В веб-интерфейсе (http://localhost:3000) отображается статус браузера
- При проблемах с UID вы получите уведомления
- В консоли отображаются логи о статусе авторизации

## Что делать если UID перестал работать
1. Получите новый UID любым из способов выше
2. Обновите UID в настройках
3. Перезапустите приложение
