## 🚀 Как использовать

### 1. Запуск приложения
```bash
npm run dev
```

### 2. Переход на вкладку "Assessment Zone"
- Откройте приложение в браузере
- Нажмите на вкладку "Assessment Zone"

### 3. Использование функций
- **Фильтрация**: используйте фильтры для поиска нужных токенов
- **Сортировка**: кликайте на заголовки колонок
- **Обновление**: нажмите кнопку "Refresh"
- **Просмотр**: кликайте "View" для открытия объявления

## 📊 Структура данных

```typescript
interface AssessmentEntry {
  token: string;           // "DOGE", "SHIB", etc.
  startDate: string;       // "2024-01-15"
  endDate?: string;        // "2024-02-05" (если завершено)
  url: string;            // ссылка на объявление
  status: 'active' | 'completed';
  duration?: number;       // дни в оценке
  isNew?: boolean;         // флаг новой записи
  lastUpdated: string;     // время обновления
}
```

## 🔧 Архитектура

### Node.js версия (для сервера)
- Полный парсинг MEXC с HTTP-запросами
- Puppeteer для динамического контента
- Файловое хранение данных
- EventEmitter для уведомлений

### Браузерная версия (для UI)
- API-вызовы вместо прямого парсинга
- Симуляция данных для демонстрации
- Совместимость с браузером
