# MEXC Trading Terminal 🚀

Профессиональный торговый терминал для биржи MEXC с интеграцией браузерного расширения и реальными API ключами.

## ✨ Основные возможности

- 📊 **Реальный ордербук** - данные с MEXC API в реальном времени
- 💰 **Баланс аккаунта** - отображение реального баланса
- 🔑 **Управление профилями** - система профилей с API ключами
- 🌐 **Браузерное расширение** - интеграция с ADS Power
- 🔄 **CORS прокси** - обход ограничений браузера
- 📱 **Адаптивный интерфейс** - современный UI/UX

## 🛠 Технологии

- **Frontend**: React 18 + TypeScript + Vite
- **Стилизация**: Tailwind CSS
- **Состояние**: Zustand
- **API**: MEXC REST API с HMAC подписью
- **Прокси**: Express.js для обхода CORS
- **Расширение**: Chrome Extension API

## 🔧 Настройка

### API ключи MEXC
1. Создайте API ключи в [MEXC](https://www.mexc.com/user/api)
2. В приложении создайте профиль с вашими ключами
3. Выберите профиль для торговли

### Браузерное расширение
1. Откройте `chrome://extensions/`
2. Включите "Режим разработчика"
3. Нажмите "Загрузить распакованное расширение"
4. Выберите папку `browser-extension`

## 🌐 Порты

- **3001** - Vite dev server (приложение)
- **3003** - CORS прокси (MEXC API)
- **3000** - WebSocket сервер (если нужен)

## 🐛 Решение проблем

### API не работает
1. Убедитесь, что CORS прокси запущен: `npm run proxy`
2. Проверьте health check: http://localhost:3003/health
3. Проверьте API ключи в профиле
4. Откройте консоль браузера (F12) для логов

### Расширение не работает
1. Убедитесь, что расширение загружено в Chrome
2. Проверьте, что сервер запущен на порту 3001
3. Обновите расширение после изменений

### CORS ошибки
1. Запустите CORS прокси: `npm run proxy`
2. Убедитесь, что прокси работает на порту 3003
3. Проверьте настройки браузера
