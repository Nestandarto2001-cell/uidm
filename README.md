# MEXC Assessment Trader

Профессиональный торговый бот для MEXC с поддержкой API и браузерной автоматизации, включающий продвинутые системы мониторинга, логирования и резервных стратегий.

## 🚀 Быстрый старт

### 1. Получение UID
```bash
npm run get-uid
```
Следуйте инструкциям в терминале для получения UID из браузера.

### 2. Установка UID
```bash
# Windows
set MEXC_UID=ваш_uid_здесь

# Linux/Mac  
export MEXC_UID=ваш_uid_здесь
```

### 3. Запуск
```bash
npm run dev
```

### 4. Открыть интерфейс
Перейдите на http://localhost:3000

## 🔧 Настройка

### Переменные окружения
- `MEXC_UID` - ваш UID из cookies браузера (обязательно)
- `MEXC_KEY` - API ключ (опционально)
- `MEXC_SECRET` - API секрет (опционально)
- `LOG_LEVEL` - уровень логирования (error, warn, info, debug)
- `LOG_TO_FILE` - запись логов в файлы (true/false)

### Конфигурация
Настройки в `src/config.ts`:
- `headless` - режим браузера (true/false)
- `pollMs` - интервал обновления данных
- `statusCheckInterval` - интервал проверки статуса
- `apiTimeout` - таймаут API запросов
- `browserTimeout` - таймаут браузера

## 📊 Мониторинг

### Веб-интерфейс

- **Файлы логов** - `logs/error.log`, `logs/combined.log`
- **Ротация логов** - автоматическая очистка старых файлов
- **Структурированные логи** - JSON формат с метаданными

- Работа без интернета
- Автоматическое восстановление

### Альтернативные API

- Автоматическое переключение
- Мониторинг доступности

## ⚠️ Важно

- UID может перестать работать - система автоматически уведомит об этом
- При проблемах с UID запустите `npm run get-uid` для получения нового
- API ключи не обязательны - бот работает и через браузер
- Логи сохраняются в папке `logs/` для диагностики проблем
- Health check endpoints доступны для мониторинга в продакшене

- Валидация всех входных данных
