# MEXC Trading Terminal

Веб-приложение для торговли на бирже MEXC с удобным интерфейсом торгового терминала.

## Особенности

- 🚀 **Веб-интерфейс** - работает прямо в браузере
- 📊 **Real-time данные** - ордербук и рыночные данные в реальном времени
- 💼 **Торговые операции** - размещение и отмена ордеров
- 🔐 **Безопасность** - API ключи хранятся локально в браузере
- 🎨 **Современный UI** - темная тема с удобным интерфейсом

## Быстрый старт

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Запустите в режиме разработки:**
   ```bash
   npm run dev
   ```

3. **Откройте в браузере:**
   - Обычный браузер: `http://localhost:5173`
   - Антидетект браузер: скопируйте ссылку в адресную строку

4. **Настройте API:**
   - Войдите в свой аккаунт MEXC
   - Создайте API ключи с правами на торговлю
   - Введите ключи в приложении

## Использование

### Настройка API
1. Перейдите в настройки API в MEXC
2. Создайте новый API ключ с правами:
   - ✅ Spot Trading
   - ❌ Futures Trading
   - ❌ Withdraw (не обязательно)
3. Скопируйте API Key и Secret
4. Введите их в приложении

### Торговля
- **Выбор символа**: Используйте выпадающий список в шапке
- **Ордербук**: Показывает лучшие цены покупки/продажи
- **Размещение ордеров**: 
  - Limit orders: укажите цену и количество
  - Market orders: только количество
- **Управление ордерами**: просмотр и отмена активных ордеров

## Технические детали

### Стек технологий
- **Frontend**: React + TypeScript
- **Styling**: Tailwind CSS
- **API**: CCXT для взаимодействия с MEXC
- **WebSocket**: Real-time данные с MEXC

### Архитектура
- Компонентная архитектура React
- Хуки для WebSocket соединения
- Локальное хранение API ключей
- Прямое подключение к MEXC API

### Безопасность
- API ключи не передаются на серверы
- Все данные хранятся локально в браузере
- Подключение напрямую к MEXC (без прокси)

## Устранение неполадок

### WebSocket не подключается
- Проверьте интернет соединение
- Убедитесь, что MEXC доступен в вашем регионе
- Попробуйте обновить страницу

### API ошибки
- Проверьте правильность API ключей
- Убедитесь, что у ключей есть права на торговлю
- Проверьте лимиты API в MEXC

### Ордера не размещаются
- Проверьте баланс на бирже
- Убедитесь в правильности количества и цены
- Проверьте статус рынка (торги могут быть приостановлены)
