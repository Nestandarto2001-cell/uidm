# MEXC Assessment Trader

Торговый бот для MEXC с поддержкой API и браузерной автоматизации.

## 🚀 Быстрый старт

### 1. Получение UID
```bash
npm run get-uid
```
Следуйте инструкциям в терминале для получения UID из браузера.

### 2. Установка UID
```bash
# Windows
set MEXC_UID=ваш_uid_здесь

# Linux/Mac  
export MEXC_UID=ваш_uid_здесь
```

### 3. Запуск
```bash
npm run dev
```

### 4. Открыть интерфейс
Перейдите на http://localhost:3000

## 📋 Возможности

- ✅ **Автоматический мониторинг статуса** - уведомления о проблемах с UID
- ✅ **Веб-интерфейс** - удобное управление через браузер
- ✅ **API + Браузер** - автоматическое переключение между методами
- ✅ **Real-time данные** - обновление стакана в реальном времени
- ✅ **Торговля** - лимитные и рыночные ордера

## 🔧 Настройка

### Переменные окружения
- `MEXC_UID` - ваш UID из cookies браузера
- `MEXC_KEY` - API ключ (опционально)
- `MEXC_SECRET` - API секрет (опционально)

### Конфигурация
Настройки в `src/config.ts`:
- `headless` - режим браузера (true/false)
- `pollMs` - интервал обновления данных
- `statusCheckInterval` - интервал проверки статуса

## 📊 Мониторинг

- **Статус в интерфейсе** - индикатор работы браузера
- **Уведомления** - всплывающие сообщения об ошибках
- **Консольные логи** - подробная информация о работе

## 🛠️ Команды

```bash
npm run dev      # Запуск в режиме разработки
npm run build    # Сборка проекта
npm start        # Запуск продакшн версии
npm run get-uid  # Получение UID из браузера
```

## ⚠️ Важно

- UID может перестать работать - система автоматически уведомит об этом
- При проблемах с UID запустите `npm run get-uid` для получения нового
- API ключи не обязательны - бот работает и через браузер
