# MEXC Trading Terminal

Профессиональный торговый терминал для MEXC с расширенным функционалом и мониторингом Assessment Zone.

## 🚀 Возможности

### Торговые функции
- **Real-time Order Book** - Отображение стакана заявок в реальном времени (до 15 уровней)
- **Профессиональный интерфейс** - Cyberpunk стиль с неоновыми акцентами
- **API интеграция** - Подключение к MEXC API для торговли
- **Множественные профили** - Управление несколькими API ключами
- **Избранные пары** - Быстрый доступ к популярным торговым парам
- **Автокомплит** - Умный поиск торговых пар
- **Расширенные ордера** - Лимитные, стоп-лосс, тейк-профит

### Assessment Zone Monitor
- **Автоматический мониторинг** - Сбор токенов из оценочной зоны MEXC
- **Real-time уведомления** - Оповещения о новых и завершенных оценках
- **Фильтрация и сортировка** - По статусу, дате, токену
- **История токенов** - Отслеживание всех периодов оценки
- **Timezone поддержка** - UTC+8 и локальное время

### Расширение браузера
- **Bridge архитектура** - Безопасная коммуникация без прямых chrome API
- **Автоматический ретрай** - Восстановление соединения при сбоях
- **Content scripts** - Сбор данных с MEXC и терминала
- **Service Worker** - Фоновая обработка и планировщик

## 📦 Установка

### 1. Установка расширения браузера

1. Откройте Chrome и перейдите в `chrome://extensions/`
2. Включите "Режим разработчика" (Developer mode)
3. Нажмите "Загрузить распакованное расширение" (Load unpacked)
4. Выберите папку `browser-extension`

### 2. Настройка CORS (ОБЯЗАТЕЛЬНО!)

**Критически важно для работы с MEXC API:**

1. Установите [CORS Unblock](https://chrome.google.com/webstore/detail/cors-unblock/lfhmikememgdcahcdlaciloancbhjino) или аналогичное расширение
2. Включите расширение в браузере
3. Обновите страницу MEXC (`https://www.mexc.com/`)
4. **Проверьте статус подключения** в терминале

> **⚠️ Без CORS расширения** браузер блокирует cross-origin запросы к MEXC API, поэтому реальное время данные и торговые функции не работают.

### 3. Запуск приложения

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Запуск тестов
npm test
```

## ⚙️ Настройка

### Способы подключения

#### 1. API ключ MEXC (Spot/Futures)
- **Назначение**: Прямая торговля и отображение баланса
- **Получение**: [MEXC API Management](https://www.mexc.com/user/api)
- **Разрешения**: Чтение, торговля, вывод (по необходимости)
- **Безопасность**: IP whitelist, ограничения по времени

#### 2. Чтение публичных данных через CORS
- **Назначение**: Просмотр стаканов и графиков без авторизации
- **Требования**: CORS расширение в браузере
- **Ограничения**: Только чтение публичных данных

#### 3. Режим Assessment Zone
- **Назначение**: Мониторинг оценочной зоны, просмотр новых токенов
- **Требования**: Не требует подключения к API
- **Функции**: Отслеживание периодов оценки, уведомления

### Настройка API ключей

1. Перейдите на [MEXC](https://www.mexc.com/)
2. Создайте API ключ в разделе **API Management**
3. Настройте разрешения:
   - ✅ **Read** - Чтение баланса и ордеров
   - ✅ **Trade** - Размещение ордеров
   - ❌ **Withdraw** - Вывод средств (только при необходимости)
4. Добавьте IP адреса в whitelist
5. В терминале нажмите **"Создать профиль"**
6. Введите данные и сохраните

### Подключение расширения

1. Откройте [MEXC](https://www.mexc.com/) в новой вкладке
2. Убедитесь, что расширение активно (иконка в панели инструментов)
3. В терминале перейдите на вкладку **"Trading"**
4. Нажмите **"Подключить браузер"**
5. Статус должен измениться на **"Подключено"**

## 🛠️ Устранение проблем

### Диагностика подключения

#### Расширение не подключается
1. **Проверьте CORS расширение** - Должно быть активно
2. **Обновите страницу MEXC** - Перезагрузите `https://www.mexc.com/`
3. **Перезапустите расширение** в `chrome://extensions/`
4. **Проверьте host_permissions** в manifest.json

#### API не работает
1. **Проверьте API ключи** - Правильность Key и Secret
2. **Убедитесь в разрешениях** - Read и Trade включены
3. **Проверьте IP whitelist** в настройках MEXC
4. **Проверьте CORS** - Расширение должно быть активно

#### Данные не обновляются
1. **Проверьте подключение к интернету**
2. **Обновите страницу терминала**
3. **Перезапустите приложение**
4. **Проверьте логи в DevTools**

### Статусы подключения

- **🟢 Connected** - Успешное подключение к API
- **🔴 Disconnected** - Проблемы с подключением
- **🟡 Connecting** - Попытка подключения
- **⚪ Unknown** - Статус не определен

### Частые ошибки

#### "CORS policy blocks the request"
**Решение**: Установите и активируйте CORS расширение

#### "Extension ID not specified"
**Решение**: Перезагрузите расширение в `chrome://extensions/`

#### "API key invalid"
**Решение**: Проверьте правильность ключей и IP whitelist

#### "Assessment Zone not updating"
**Решение**: Проверьте подключение расширения и обновите страницу
