# 👤 Руководство по профилям пользователей

## 🎯 Что нового

### ✅ **Система профилей пользователей**
- **Множественные аккаунты** - создавайте профили для разных MEXC аккаунтов
- **UID и API ключи** - храните данные для каждого профиля отдельно
- **Запоминание данных** - автоматическое сохранение с галочками
- **Быстрое переключение** - переключайтесь между профилями одним кликом

### ✅ **Улучшенный интерфейс**
- **Свернутые разделы** - инструкции, помощь и методы подключения в выпадающих окнах
- **Компактный дизайн** - все элементы организованы логично
- **Визуальные индикаторы** - статус подключения и активный профиль
- **Адаптивная верстка** - работает на всех устройствах

## 🚀 Как использовать

### 1. Создание профиля
1. Нажмите **"+ Новый профиль"**
2. Заполните данные:
   - **Имя профиля** (например: "Мой основной аккаунт")
   - **MEXC UID** (ваш уникальный идентификатор)
   - **API Key** (ключ API)
   - **API Secret** (секретный ключ)
3. Поставьте галочку **"Запоминать данные"**
4. Нажмите **"Сохранить"**

### 2. Переключение между профилями
- Кликните на любой профиль в списке
- Статус **"Активен"** покажет текущий профиль
- API ключи автоматически загрузятся

### 3. Подключение к MEXC
1. **Выберите метод подключения** (расширение рекомендуется)
2. **Нажмите "Открыть MEXC"** - откроется правильная страница
3. **Следуйте инструкциям** в развернутых разделах

## 🔧 Решение проблем

### ❌ Не открывается MEXC
- Проверьте блокировщик всплывающих окон
- Попробуйте открыть в новой вкладке вручную
- Очистите кэш браузера

### ❌ Не работает подключение
- Обновите страницу MEXC
- Проверьте, что расширение включено
- Убедитесь, что ордербук отображается

### ❌ Проблемы с профилями
- Проверьте правильность API ключей
- Убедитесь, что профиль активен
- Попробуйте создать новый профиль

## 📱 Интерфейс

### 🎛️ **Управление профилями**
- **Список профилей** - все созданные профили
- **Кнопки действий** - редактирование ✏️ и удаление 🗑️
- **Статус активности** - зеленый индикатор активного профиля

### 🔗 **Подключение к MEXC**
- **Быстрые действия** - кнопки "Открыть MEXC" и "Расширения Chrome"
- **Выпадающие разделы**:
  - **Методы** - выбор способа подключения
  - **Инструкции** - пошаговое руководство
  - **Помощь** - устранение неполадок

### 📊 **Индикаторы статуса**
- **🟢 Зеленый** - подключен к MEXC
- **🔴 Красный** - не подключен
- **Синий** - активный профиль

## 💾 Хранение данных

- **Профили** сохраняются в localStorage браузера
- **API ключи** защищены локальным хранением
- **Настройки** запоминаются между сессиями
- **Безопасность** - данные не передаются на серверы
