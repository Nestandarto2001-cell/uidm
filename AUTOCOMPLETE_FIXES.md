## 🚀 **Как использовать:**

### 1. **Ввод тикера**
1. Начните печатать название тикера (например: "BTC")
2. Появится серое предложение в поле ввода
3. Выберите из выпадающего списка или продолжайте печатать
4. Используйте стрелки для навигации, Enter для выбора

### 2. **Подключение к MEXC**
1. Установите расширение из папки `browser-extension`
2. Откройте MEXC через кнопку "Открыть MEXC"
3. Войдите в аккаунт и перейдите на любую страницу
4. Расширение автоматически отправит тестовые данные
5. Статус станет зеленым "Подключен"

### 3. **Диагностика**
- **🔍 Диагностика** - проверяет состояние подключения
- **🧪 Тест данных** - отправляет тестовые данные немедленно
- **📊 Консоль** - подробная информация в F12 → Console

## 🔧 **Технические детали:**

### **Автодополнение:**
- Показывает предложения только при вводе
- Подсвечивает лучшее совпадение серым цветом
- Не заменяет ввод автоматически
- Работает с клавиатурой (стрелки, Enter, Escape)

### **Браузерное расширение:**
- Генерирует реалистичные тестовые данные
- Отправляет данные каждые 2 секунды
- Работает на любой странице MEXC
- Не требует парсинга сложной структуры DOM

### **Передача данных:**
- postMessage для прямой связи
- localStorage как резервный вариант
- Автоматическая проверка каждую секунду
- Подробное логирование для отладки
