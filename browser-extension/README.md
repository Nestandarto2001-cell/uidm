# MEXC Trading Terminal - Browser Extension

## 🚀 Установка расширения

### Chrome
1. Откройте `chrome://extensions/`
2. Включите "Режим разработчика" (Developer mode)
3. Нажмите "Загрузить распакованное расширение" (Load unpacked)
4. Выберите папку `browser-extension`
5. Убедитесь, что расширение включено

### Edge
1. Откройте `edge://extensions/`
2. Включите "Режим разработчика" (Developer mode)
3. Нажмите "Загрузить распакованное расширение" (Load unpacked)
4. Выберите папку `browser-extension`
5. Убедитесь, что расширение включено

## ⚙️ Настройка доступа

### Разрешения сайта
1. После установки расширения нажмите на его иконку
2. Выберите "Управление расширением" (Manage extension)
3. В разделе "Разрешения сайта" (Site access):
   - Выберите "На всех сайтах" (On all sites) ИЛИ
   - Добавьте домен вашего терминала вручную

### Инкогнито режим
1. В настройках расширения включите "Разрешить в режиме инкогнито"
2. Это необходимо для работы в приватных вкладках

## 🔧 Настройка домена

**ВАЖНО**: Перед использованием замените плейсхолдер в `manifest.json`:

```json
"https://YOUR-TERMINAL-DOMAIN/*"
```

На ваш реальный домен терминала, например:
```json
"https://mytradingterminal.com/*"
```

## 🧪 Тестирование

### Проверка работы расширения
1. Откройте терминал в браузере
2. Нажмите кнопку "Диагностика" в шапке
3. Проверьте статусы:
   - ✅ Браузер: должен показывать userAgent
   - ✅ Расширение (мост): "Обнаружено"
   - ✅ Связь с расширением: "Успешно"
   - ✅ Доступ к MEXC API: "Успешно"

### Консольные тесты
Откройте консоль браузера (F12) и выполните:

```javascript
// Тест связи с расширением
window.postMessage({source:'MEXC_TT', type:'PING'}, '*');
// Должен вернуть {type:'PONG'}

// Тест API через расширение
window.postMessage({source:'MEXC_TT', type:'PROBE'}, '*');
// Должен вернуть данные от MEXC API
```

## 🐛 Решение проблем

### Расширение не обнаружено
1. Убедитесь, что расширение установлено и включено
2. Проверьте разрешения доступа к сайту
3. Перезагрузите страницу терминала
4. Проверьте консоль браузера на ошибки

### CORS ошибки
1. Убедитесь, что CORS правила загружены
2. Проверьте, что домен терминала добавлен в разрешения
3. Перезапустите расширение

### API не работает
1. Проверьте API ключи в профиле
2. Убедитесь, что ключи имеют необходимые разрешения
3. Проверьте доступность MEXC API

## 📁 Структура файлов

```
browser-extension/
├── manifest.json          # Конфигурация расширения
├── background.js          # Service Worker для API запросов
├── content.js            # Мост между страницей и расширением
├── popup.html            # Интерфейс popup
├── popup.js              # Логика popup
├── rules/
│   └── cors.json         # CORS правила для MEXC API
└── icons/                # Иконки расширения
```

## 🔒 Безопасность

- Все API запросы идут через background script
- API ключи не сохраняются в расширении
- CORS правила ограничены доменами MEXC
- Расширение работает только на разрешенных сайтах

## 📞 Поддержка

При возникновении проблем:
1. Проверьте диагностику в терминале
2. Посмотрите логи в консоли браузера
3. Убедитесь в правильности настроек расширения
4. Проверьте доступность MEXC API
